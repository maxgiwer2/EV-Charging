# 09 Development Roadmap

## M0 Foundation
Repository, Laravel/PHP setup, Docker optional, CI, env, coding standards.

## M1 Core
Auth/RBAC, vehicles, stations, networks, charging sessions, database.

## M2 Receipts
Private storage, upload, OCR abstraction, review UI, duplicate detection.

## M3 Analytics
Cost engine, dashboard, filters, reports, exports.

## M4 Tariff
Versioned tariff, home charging, TOU/peak-off-peak, snapshotting.

## M5 AI
AI assistant, anomaly detection, forecasting.

## M6 Production
Security hardening, tests, backup/restore, observability, deployment.

Each milestone requires tests, documentation, migration status, and a demoable increment.
