# 01 Project Overview

## Goal
สร้างระบบบันทึก วิเคราะห์ และจัดการค่าใช้จ่ายการชาร์จ EV โดยรองรับการกรอกเองและ Receipt OCR/AI

## MVP
- Authentication/RBAC
- Vehicle management
- Charging session
- Charging station/network
- Receipt upload
- OCR + review
- Cost calculation
- Dashboard
- Search/filter
- CSV/Excel/PDF export

## Future
- Home/TOU tariff engine
- Solar charging
- AI assistant
- anomaly detection
- forecasting
- maps
- mobile app
- fleet/multi-organization
- charger/smart meter integrations

## Design Principles
- API-first
- modular services
- mobile responsive
- secure by default
- auditable financial records
- provider-independent OCR/AI
- configurable tariffs
